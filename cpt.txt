Network Configuration
Parameter	Example Value
Wireless Router	WRT300N
SSID	As required
Security	WPA2-PSK
Password	As required
Gateway IP	192.168.0.1
Subnet Mask	255.255.255.0
DHCP Start IP	192.168.0.2
Maximum Users	10
Connected Devices	Laptop0, Laptop1, etc.

Procedure
1.	Open Cisco Packet Tracer.
2.	From Network Devices → Wireless Devices, select WRT300N Wireless Router and place it in the workspace.
3.	From End Devices, select the required number of Laptop-PT devices.
4.	Open the router’s Config tab, select Wireless, and configure the SSID.
5.	Select WPA2-PSK or another available security option and enter a password.
6.	Open the router’s GUI tab and configure the Internet Connection Type as DHCP.
7.	Configure the gateway IP address and subnet mask. For example:
o	Gateway IP: 192.168.0.1
o	Subnet Mask: 255.255.255.0
8.	Configure the DHCP start IP address, such as 192.168.0.2, and set the maximum number of users according to the requirement. Save the changes.
9.	For each laptop, open the Physical tab, switch off the laptop, and install the WPC300N Wireless Ethernet Module in the LAN Ethernet port. Switch the laptop on.
10.	Open the laptop’s Desktop → PC Wireless application. Select the Connect tab and connect to the configured wireless router.
11.	Enter the router’s wireless password when prompted.
12.	Repeat the same procedure for all remaining laptops.
13.	Open Desktop → Command Prompt on Laptop0 and use the ping command to test connectivity with the router’s gateway IP address.
14.	Use the ping command to test connectivity with the DHCP-assigned IP address of Laptop1 and other connected laptops.
